# بدائل بيانات XAUUSD — بحث غير مفعّل

طلب المستخدم تقييم مصدر آخر لا يحتاج جهازًا شخصيًا يعمل باستمرار أو اشتراكًا مدفوعًا. لم يُعتمد أو يُربط مصدر جديد بعد؛ لا توجد نتائج سوق جديدة أو نشر إشارات آلي نتيجة هذا البحث. لا تُخلط أسعار الوسطاء أو عقود CFD والعقود الدائمة والعملات الذهبية.

## Dukascopy: مرشح فني، لا ترخيص مثبت

راجعت مصدر مكتبة [dukascopy-node](https://github.com/Leo4815162342/dukascopy-node). تعريف الأداة في `src/utils/instrument-meta-data/generated/instrument-meta-data.json` يتضمن `XAU/USD`، ووجود تاريخ لشموع الدقيقة. دالة `getRealTimeRates` موسومة experimental وتعيد استخدام جلب التاريخ، ولذلك اسمها ليس إثباتًا لسرعة وصول الأسعار أو اكتمال أحدث دقيقة.

المكتبة نفسها تقول إنها ليست تابعة أو معتمدة من Dukascopy وإنها مخصصة للبحث والتعليم. رخصة مكتبة برمجية لا تمنح تلقائيًا حق إعادة نشر أسعار المزود أو استخدامها تجاريًا. لم يتم التحقق من شروط Dukascopy الرسمية، أو وجود API بلا حساب، أو حدود الطلبات والتأخير الفعلي في بيئة الإنتاج. لا يصح وصفها بأنها حل مجاني جاهز للمشتركين.

ملف `src/config/data-api.ts` يحدد الأصل `https://jetta.dukascopy.com/v1`؛ هذا مستخرج من عميل طرف ثالث، وليس مواصفات API رسمية مثبتة. يلزم أولًا الوصول إلى `www.dukascopy.com` لمراجعة الشروط والتوثيق وإلى مضيف البيانات للتحقق المسموح، دون تجاوز أي رفض وصول. النطاقان غير موجودين في سياسة بيئة العمل الحالية وقت بدء البحث. لا تُشترى خطط ولا تسجّل حسابات ولا تُفعّل إعادة توزيع بيانات كجزء من القراءة.

## OANDA v20: واجهة رسمية، تحتاج تهيئة حساب

المصدر الرسمي [v20-openapi](https://github.com/oanda/v20-openapi/blob/master/yaml/separate/v20_instrument.yaml) يوثق جلب الشموع عبر `GET /v3/instruments/{instrument}/candles`، ومكوّنات bid/ask/mid، وتصفية الشموع المكتملة. أمثلة [OANDA الرسمية](https://github.com/oanda/v20-python-samples) توضّح أن الاتصال يحتاج API token وإعداد حساب؛ بيئة practice منفصلة عن الحساب الحقيقي.

هذا مصدر خادمي لا يحتاج MT5 على موبايل أو كمبيوتر المستخدم، لكنه ليس وصولًا عامًا بلا حساب. توافر الذهب يعتمد أدوات الحساب والجهة والمنطقة؛ لا يُفترض أن كل حساب يتيح `XAU_USD`، ولا تُفترض صلاحية تجارية مجانية لموقع مشتركين. لا تُستخدم صلاحيات تداول أو حساب حقيقي لجلب بيانات فقط، ولا تُطلب كلمات مرور أو مفاتيح في المحادثة.

## Twelve Data: يلزم التحقق من الخطة

راجعت [عميل Python الرسمي](https://github.com/twelvedata/twelvedata-python): يوثق فريمات `1min` و`15min` والتواريخ وAPI key. هذا لا يثبت إتاحة الذهب على الخطة المجانية، أو كفاية حدودها لتشغيل مستمر، أو حق إعادة التوزيع. لا تُفعّل خطة أو تجربة مدفوعة ولا يُعتبر SDK مفتوح المصدر بديلًا عن شروط البيانات.

## Bybit MT5 ليس V5

تؤكد [وثيقة TradFi الرسمية](https://github.com/bybit-exchange/docs/blob/master/docs/v5/tradfi-integration.mdx) أن CFD/MT5 غير متاح عبر V5، بخلاف عقود Bybit الأصلية. وجود حساب MT5 لا يمنح API عام لشموعه. آخر طلب سوق مباشر من البيئة إلى Bybit أعاد حظر بلد؛ لا يُتجاوز بواسطة VPN أو وسيط أو CI.

## شروط اعتماد أي بديل

1. التأكد من حق الوصول والاستخدام المطلوب ومن عدم الحاجة إلى اشتراك مدفوع.
2. جلب أسعار و72 ساعة من بيانات حقيقية: 24 ساعة تهيئة و48 ساعة تقرير، مع إعلان الفجوات وجلسات إغلاق السوق.
3. التحقق من مصدر الأداة، bid/ask، الدقة، التوقيت UTC، التأخير، وخطوة السعر؛ لا تُستخدم رسوم العقود الدائمة افتراضيًا لعقود CFD.
4. إبقاء تقارير الإعادة التاريخية منفصلة عن الصفقات المرسلة بالفعل، وإعلان عدم حسم ترتيب TP/SL داخل الشمعة عند غياب tick data.
5. تعديل قيد مصدر الإشارات والشارت والرسائل بصورة متسقة قبل أي نشر حي، ثم اختبار طويل خارج العينة؛ لا تُفعّل استراتيجية بحثية لمجرد نجاح الاتصال.

هذه نتائج بحث وثائقي، لا تحقق حي من بيانات البدائل، ولا تعني اكتمال المشروع أو جاهزية إصدار جديد.
