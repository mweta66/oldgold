# جروب WetaGold الخاص

## العضوية عندك أنت فقط

أنشئ الجروب من حساب Telegram الشخصي واجعله **Private** بدون اسم مستخدم عام أو ربط بقناة، واقفل صلاحية Add Users للأعضاء العاديين. خليك أنت المالك، والمشرف الآخر الوحيد هو بوت الإرسال. لا تمنحه Invite Users أو Ban/Restrict Users أو Add Admins أو Change Group Info. اقفل إرسال النصوص والوسائط والاستفتاءات ومعاينات الروابط وصلاحيات تعديل المعلومات وتثبيت الرسائل وإدارة المواضيع للأعضاء العاديين؛ الإرسال للمالك والبوت فقط. الفحص يرفض الجروب إذا كانت إحدى هذه الصلاحيات مفعّلة، ويوقف إرسال الجروب دون تعطيل الرسائل الخاصة. الموقع لا يغيّر إعدادات Telegram تلقائيًا نيابة عن المالك.

أنت تضيف المشتركين وتخرجهم يدويًا داخل Telegram. الموقع لا ينشئ دعوات، ولا يوافق على انضمام، ولا يدعو أو يحظر مستخدمين. لا تنشر رابط دعوة دائم؛ ألغِ روابط الدعوة القديمة من إعدادات Telegram أو استخدم طلبات انضمام توافق عليها بنفسك. بعض معلومات روابط الدعوة والبوتات المشرفة لا يتيحها Bot API بالكامل؛ راجعها بنفسك. فحص الموقع لا يلغي روابط نشرتها سابقًا ولا يغير خصوصية الجروب.

الجروب يستقبل **كل الإشارات والتحديثات**، لذلك حصة حساب الموقع أو انتهاؤه لا يمنعان العضو من قراءة رسائل الجروب. راجع المشتركين وأخرج المنتهي بنفسك. تبقى الرسائل الخاصة بالبوت مقيدة بتفعيل الحساب والإشارات المخصصة له، وتحديثات الإشارة المستلمة لا تخصم حصة جديدة.

## الربط

1. أنشئ بوت المشروع من BotFather. ضع `TELEGRAM_BOT_TOKEN` في أسرار الخادم فقط، لا في المحادثة أو المصدر.
2. أضف البوت للجروب كمشرف إرسال بالقيود أعلاه. لا تستخدم بوت خدمة أخرى حتى لا تستبدل webhook الخاص بها.
3. ادخل بحساب المدير في WetaGold واربط Telegram من قسم الحساب واضغط Start من حساب Telegram **المالك للجروب**؛ الرابط خاص أحادي الاستخدام ولا ينشئ عضوية جروب.
4. أضف الرقم الرقمي السالب للجروب مثل `-100…` في `TELEGRAM_GROUP_CHAT_ID` داخل إعدادات Vercel وأعد النشر. لا تستخدم اسمًا عامًا أو رابط دعوة. `TELEGRAM_ADMIN_CHAT_ID` بديل قديم فقط؛ الجديد أولى، واحذف المتغيرين لتعطيل إرسال الجروب.
5. طبّق migrations 001 و002 و003 و004 بالترتيب، ثم سجل webhook وشغّل Cron المحمي كما في [دليل Supabase](SUPABASE.md). لترقية بوت حي: أوقف النشر وتعديلات الإشارات والـ Cron مؤقتًا وانتظر انتهاء الطلبات، خذ نسخة حسب خطة المشروع، طبّق الملفات غير المطبقة، انشر الكود الجديد ثم استأنف المهام؛ لا تشغّل العامل القديم مع الطابور أو أحداث الأهداف الجديدة. راجع [ترقية الأهداف](MULTIPLE-TARGETS.md).
6. من لوحة المدير اضغط «فحص خصوصية الجروب». يقرأ معلوماته ويتحقق من خصوصيته والمالك وصلاحيات الأعضاء والبوت قبل الإرسال أيضًا. إذا تعذر قراءة الصلاحيات أو كانت عامة/مفتوحة، تتوقف رسائل الجروب وتظل المحاولات محفوظة؛ الرسائل الخاصة لا تعتمد على نجاح فحص الجروب.

إضافة أعضاء أو إخراجهم من الموقع **غير موجودة عمدًا**؛ العملية عند المالك في Telegram. لا يوجد وصول لحسابك الشخصي أو إنشاء خارجي لجروب أو اختبار حي لمجرد نشر هذا الكود.

## ماذا يرسل تلقائيًا؟

في نموذج نشر المدير يظهر الخطأ بجوار زر النشر، وتبقى القيم المدخلة عند الرفض. السعر المرجعي ووقت السعر اختياريان كلٌّ على حدة بعد تطبيق migration 007؛ غيابهما لا يمنع تخصيص الإشارة أو إرسال Telegram، ولا يختلق مرجعًا بدلًا منهما. إذا أُضيف وقت السعر، يكون خلال آخر خمس دقائق وليس وقت دخول تاريخي؛ وقت النشر الفعلي يُسجّل منفصلًا. نجاح حفظ الإشارة وتخصيصها لا يعني وصول رسالة Telegram: استجابة النشر في Supabase تعرض حالة رسالة الجروب الأولى الفعلية بعد محاولة الإرسال، وتعرضها الواجهة مستقلة عن عدد المشتركين. الجروب يستقبل النشر حتى لو كان عدد المستحقين صفرًا. الانتظار أو الفشل لا يستدعي نشر صفقة جديدة؛ الطابور الدائم يعيد المحاولة، وزر إعادة الرسائل الفاشلة لا يعيد الرسائل المرسلة. تعذر قراءة الحالة يعرض عدم التأكد بدل ادعاء الإرسال.

كل نشر جديد، فتح إشارة، تسجيل الهدف **TP**، تسجيل الوقف **SL**، إلغاء، أو انتهاء صلاحية دخول. رسالة الجروب مختصرة: شراء/بيع، سعر الدخول، SL، وTP أو TP1/TP2/TP3 فقط، دون سطر وقت الصفقة أو وقت التحديث. يظل وقت الصفقة محفوظًا ومعروضًا على الموقع؛ حذف السطر من الرسالة لا يغيّر السجل. لا تعرض رسائل الجروب الشروحات أو المعرّفات أو وقت الصلاحية أو بيانات المزود، بينما تحتفظ الرسائل الخاصة بتفاصيلها السابقة. التغيير يخص الرسائل الجديدة وإعادة المحاولات؛ لا يعدّل رسائل قديمة أُرسلت بالفعل.

في التحديث يضاف وصف قصير إلى سطر النوع مثل «شراء — تحديث TP1» أو «بيع — وقف الخسارة SL»، وتظهر علامة ✓ بجوار الأهداف المسجلة فقط، حتى لا يبدو التحديث إشارة جديدة. تنبيهات الحالات غير المحسومة تظل مميزة ولا تتحول إلى مكسب أو خسارة. تبقى تفاصيل المصدر وحدود الرصد ظاهرة على الموقع وفي الرسائل الخاصة. النشر وتحديث الحالة وإضافة الرسائل للطابور مرتبطون بمعاملة قاعدة البيانات؛ قراءة السجل أو إعادة النشر بنفس الطلب لا تخصم مرتين. هذا تغيير عرض فقط، بلا إعادة إرسال أو تعديل الرسائل القديمة أو نشر اختبارات تاريخية كإشارات حيّة.

المستويات هدف إلى ثلاثة أهداف مرتبة ووقف واحد، وغير قابلة للتعديل بعد النشر. كل TP له لقطة ووقت تسجيل مستقل، والهدف الأخير فقط يغلق الإشارة؛ الوقف بعد هدف جزئي يحفظ تقدم الأهداف دون ادعاء ربح مركز أو تنفيذ إغلاق جزئي. تكرار تسجيل هدف مسجّل لا يعيد الرسالة ولا يخصم حصة. الإشارات اليدوية تتبع تسجيل المدير، أما إشارات Gold API الآلية فتتبع عبور المستويات المرصود في قراءات السعر المرجعي المتقطعة؛ قد تفوت حركة بين القراءات ولا توجد مصادقة من وسيط على تنفيذ الصفقة. TradingView المضمّن ليس مصدر API لمحرك تتبع أسعار. راجع [متابعة Gold API](GOLD-MARKET.md).

الإرسال يحافظ على ترتيب الأحداث لكل محادثة ويبدأ عند طلب النشر أو تحديث الحالة. عند التزامن أو تعطل المزود، تستكمل Cron بقية الدفعات والمحاولات (حتى خمس مرات). لا يوعد بوصول فوري أو exactly-once؛ قد تتكرر رسالة إذا قبلها Telegram وانقطع الرد. المعرّفات محفوظة في الطابور ولوحة المدير والرسائل الخاصة، بينما يميّز المستخدم إشارة الجروب بوقت إصدارها ومستوياتها دون زحام المعرّفات.

عند رد 429 يحترم العامل `parameters.retry_after` بعد تحقق نوعها وحدودها ويخزن الموعد القادم في الطابور؛ لا يعاود قبل مهلة المزود حتى لو شغّلت Cron مبكرًا. لا يعرض نص خطأ المزود الخاص. المهلة لا تضمن وصول رسالة تجاوزت صلاحيتها أو تعالج وحدها حمل آلاف المستلمين؛ الدفعة الحالية حتى 20 وتحتاج متابعة واختبار توسع. شاشة تشخيص المدير تعرض معرّف الرسالة والإشارة وحالتها وعدد محاولاتها والموعد المسجّل، دون أرقام محادثات أو توكنات.

لا ترسل دعوة دخول قديمة بعد انتهاء صلاحيتها. إشعارات النتائج مسموح بإرسالها حتى 24 ساعة من تسجيل الحدث، حتى لو انتهت صلاحية الدخول؛ بعدها تلغى لتجنب تحديثات قديمة جدًا. لا تعاد كل النتائج التاريخية تلقائيًا عند التفعيل أو الترقية. فشل الخصوصية أو إزالة التوكن لا يمسح بيانات الصفقات.

اختبر الربط على مشروع وبوت اختبار قبل تفعيله للمشتركين؛ أسعار الاختبار ليست إشارات سوق حقيقية. راجع إرسال نشر ثم فتح ثم TP/SL، وانقطاع مؤقت وإعادة محاولة، وتأكد من عدم دعوة أو إخراج أي عضو بواسطة البوت.
