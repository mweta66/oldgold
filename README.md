# WetaGold

واجهة عربية متجاوبة لمنصة إشارات الذهب، مبنية كصفحة static خفيفة.

## التشغيل المحلي

لا توجد dependencies. شغّل أي خادم static من جذر المشروع، مثل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## مصدر الشارت

الشارت حي من TradingView باستخدام الرمز `OANDA:XAUUSD`. أزرار `1M` و`15M` و`1H` و`1D` تغيّر الفريم داخل الشارت. الأسعار المعروضة داخل بطاقة الإشارة لا تُملأ بقيمة ثابتة؛ مصدر السعر المرجعي هو الشارت نفسه.

## الحالة الحالية

هذه واجهة المنتج الأولى. الإشارات والأداء المعروضان بيانات توضيحية إلى أن يتم ربط محرك الإشارات وقاعدة البيانات واشتراكات المستخدمين.

## ملاحظات الإنتاج

- يجب إضافة Backend موثوق قبل نشر إشارات حية.
- يجب استبدال البيانات التوضيحية بسجل إشارات قابل للتدقيق.
- يجب إضافة صفحات إخلاء المسؤولية والخصوصية وشروط الاستخدام قبل الاشتراكات المدفوعة.
