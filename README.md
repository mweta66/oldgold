# WetaGold

واجهة عربية متجاوبة لمنصة إشارات الذهب، مبنية كصفحة static خفيفة.

## التشغيل المحلي

لا توجد dependencies. شغّل أي خادم static من جذر المشروع، مثل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## مصدر الشارت

الشارت حي من TradingView باستخدام الرمز `OANDA:XAUUSD`. أزرار `1M` و`15M` و`1H` و`1D` تغيّر الفريم داخل الشارت. الأسعار المعروضة داخل بطاقة الإشارة لا تُملأ بقيمة ثابتة؛ مصدر السعر المرجعي هو الشارت نفسه.

## الحالة الحالية

هذه واجهة المنتج الأولى. الإشارات محجوبة خلف شاشة تسجيل الدخول، وتتضمن الواجهة مسودة لوحة المدير لإدارة البريد وعدد الإشارات وتاريخ الانتهاء وربط Telegram. لا تعرض الواجهة أي صفقة أو أداء افتراضي؛ ستظل الإشارة وسجل الأداء فارغين إلى أن يتم ربط محرك إشارات وقاعدة بيانات بمصدر موثوق.

## متطلبات الربط الحقيقي

النسخة الحالية static ولا تنفذ مصادقة أو صلاحيات فعلية. قبل الإنتاج يجب إضافة Backend مع جلسات آمنة، قاعدة بيانات للحسابات (`email`, `expires_at`, `signal_quota`, `signals_used`, `role`)، وAPI يتحقق من الصلاحية قبل إرسال الإشارة. إرسال Telegram يجب أن يتم من الخادم فقط باستخدام `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` كأسرار بيئية؛ لا تُحفظ هذه القيم في المتصفح أو GitHub.

## ملاحظات الإنتاج

- يجب إضافة Backend موثوق قبل نشر إشارات حية.
- يجب استبدال البيانات التوضيحية بسجل إشارات قابل للتدقيق.
- يجب إضافة صفحات إخلاء المسؤولية والخصوصية وشروط الاستخدام قبل الاشتراكات المدفوعة.
